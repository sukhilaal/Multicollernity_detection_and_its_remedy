# Multicollernity_detection_and_its_remedy
Multicollinearity occurs in a multiple regression model when two or more independent (predictor) variables ($X_1, X_2, \dots, X_p$) are highly correlated with each other. In simple terms, one predictor variable can be linearly predicted from the others with a substantial degree of accuracy
